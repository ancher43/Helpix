## 💡 Особенности и реализованный функционал

### 1. Гибридный поиск (Hybrid Search) на базе RRF
Система одновременно выполняет два независимых типа поиска:
1. **Полнотекстовый поиск (Lexical Search):** поиск по ключевым словам и точным совпадениям терминов в заголовках, тегах и тексте статей (русский и английский языки).
2. **Семантический поиск (Dense Vector Search):** векторизация запроса с помощью нейросетевой модели `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (384-мерные эмбеддинги) и вычисление косинусной близости.
3. **Объединение по формуле RRF (Reciprocal Rank Fusion):**
   $$RRF(d) = \sum_{m \in M} \frac{1}{k + r_m(d)}$$
   где $k = 60$ — стандартная константа сглаживания, $r_m(d)$ — порядковый ранг документа $d$ в $m$-й системе ранжирования.  
   *Преимущество:* в отличие от простого взвешивания оценок, RRF не требует нормализации шкал и устойчив к выбросам.

### 2. Автоматическое выявление и кластеризация поисковых пробелов
Система автоматически регистрирует запрос как **поисковый пробел** в двух случаях:
* Поиск вернул **0 результатов** (тема вообще не представлена в базе знаний).
* Поиск вернул результаты, но оператор нажал кнопку **«Ответ не помог»** (материал неактуален или неполон).

**Пайплайн кластеризации:**
1. Извлечение неразобранных пробелов из журнала `search_logs`.
2. Извлечение векторных представлений запросов операторов.
3. Кластеризация алгоритмом **Agglomerative Clustering** (агломеративная иерархическая кластеризация с усредненной связью и косинусной метрикой).
4. Оценка качества кластеризации через **Silhouette Score** (коэффициент силуэта).
5. Автоматическое определение названия темы (нахождение медоида кластера) и ключевых терминов через **TF-IDF**.
6. Понижение размерности методом **PCA** для 2D-визуализации тем на дашборде.
7. Предоставление модератору кнопки **«Написать статью»**, которая автоматически открывает редактор с заполненным заголовком и ключевыми словами темы.

### 3. Рабочее место оператора
* Мгновенное переключение алгоритмов поиска: *Гибридный (RRF)*, *По тексту (BM25)*, *По смыслу (Vector)*.
* Фильтрация по языкам (RU / EN) и категориям базы знаний.
* Детализированная плашка ранжирования под каждым результатом (RRF Score, текстовый ранг, семантический ранг, % сходства).
* Просмотр статьи в удобном модальном окне с подсветкой синтаксиса и кнопками обратной связи («Помогло» / «Ответ не помог»).

### 4. Аналитическая панель модератора
* Метрики эффективности базы знаний (Всего статей, Поисков, Пробелов, Процент непокрытых запросов).
* График динамики поисков и пробелов за 7 дней.
* Топ частых запросов и рейтинг полезности статей.
* Журнал последних поисковых пробелов.

## 🗄️ Настройка подключения к PostgreSQL

В проекте реализован автоматический отказоустойчивый механизм:
* Если PostgreSQL настроен и доступен, система работает напрямую с PostgreSQL.
* Если параметры подключения ещё не заданы, система бесшовно переключается на встроенную локальную БД, позволяя полноценно тестировать функционал.

Для переключения на ваш локальный PostgreSQL отредактируйте файл `D:\VKR\backend\.env`:
```ini
DB_USER=postgres
DB_PASSWORD=ваш_пароль_от_postgres
DB_HOST=localhost
DB_PORT=5432       # или 5433 в зависимости от версии службы
DB_NAME=vkr_knowledge_base
```
После указания пароля запустите генератор тестовых данных:
```powershell
cd D:\VKR\backend
..\venv\Scripts\python scripts\seed_data.py
```
